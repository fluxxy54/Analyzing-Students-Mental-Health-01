# Analyzing Students Mental Health

A comprehensive data analysis project focused on understanding and analyzing the mental health patterns and trends among students. This project aims to identify key factors affecting student mental well-being and provide insights through statistical analysis and data visualization.

## 📋 Project Overview

Mental health is a critical aspect of student well-being that significantly impacts academic performance, social relationships, and overall quality of life. This project explores various factors that influence students' mental health, including:

- **Academic stress and pressure**
- **Social connectedness and isolation**
- **International vs. domestic student experiences**
- **Age and academic year correlations**
- **Depression and anxiety trends**
- **Suicidal ideation patterns**
- **Coping mechanisms and support systems**

## 🎯 Objectives

1. **Identify Risk Factors**: Analyze demographic and academic factors that contribute to mental health issues
2. **Track Trends**: Monitor mental health patterns across different student populations and time periods
3. **Correlation Analysis**: Investigate relationships between various mental health indicators
4. **International Student Focus**: Special emphasis on challenges faced by international students
5. **Predictive Insights**: Develop understanding for early intervention strategies

## 📊 Dataset Features

The analysis typically includes variables such as:

- **Demographics**: Age, gender, nationality, academic year
- **Academic Information**: Field of study, GPA, academic load
- **Mental Health Indicators**: Depression scores, anxiety levels, stress measures
- **Social Factors**: Social connectedness, isolation levels, support systems
- **Behavioral Patterns**: Sleep patterns, exercise habits, social activities
- **International Student Specific**: Acculturative stress, homesickness, language barriers

## 🚀 Getting Started

### Prerequisites
```bash
Python 3.7+
Jupyter Notebook
Required Python packages (see requirements.txt)
```

### Installation
```bash
# Clone the repository
git clone https://github.com/fluxxy54/Analyzing-Students-Mental-Health-01.git

# Navigate to project directory
cd Analyzing-Students-Mental-Health-01

# Install required packages
pip install -r requirements.txt

# Launch Jupyter Notebook
jupyter notebook
```

### Usage
1. Place your dataset in the `data/` directory
2. Run the data preprocessing notebook
3. Execute the exploratory data analysis
4. Review visualization outputs
5. Analyze statistical findings
